# docs

this directory contains the canonical documentation for alembic.

## contents

- `docs/ir.md` - canonical ir schema and object model
- `docs/inventory.md` - inventory (ir) file format (yaml/json) and includes
- `docs/map.md` - ir to ir transformation between vocabularies
- `docs/engine.md` - loader, validation, planning, apply
- `docs/plan.md` - plan json schema and semantics
- `docs/state.md` - state store format and behavior
- `docs/cli.md` - cli usage and examples
- `docs/configuration.md` - cli configuration
- `docs/cast.md` - django app generation from an inventory
- `docs/netbox.md` - netbox adapter mapping and constraints
- `docs/nautobot.md` - nautobot adapter mapping and constraints
- `docs/infrahub.md` - infrahub adapter mapping and constraints
- `docs/external-adapters.md` - process-based external adapter protocol
- `docs/development.md` - building, testing, and release flow
- `docs/case-studies/README.md` - end-to-end examples and walkthroughs
